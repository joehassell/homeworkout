## Executive summary

The generator is built on a sensible architecture (capability filter, focus weighting, cat-round-robin, time reconciliation), and the exercise database is large and largely well-tagged. But the corpus reveals nine systemic issues that all have small, surgical fixes:

| # | Issue | Severity | Where |
|---|---|---|---|
| 1 | **Yoga ignores capability filter** — pregnant/elderly/limited get Chaturanga, Up-Dog, deep prone work, floor-only poses | **Critical (safety)** | `js/yoga.js:381` |
| 2 | HIIT pool is too narrow — 11 exercises appear in 100 %+ of HIIT workouts; 100 % of HIIT workouts contain zero pulling | **High** | `js/exercises.js` (only 52 HIIT-tagged, 4 pulls) |
| 3 | Strength ordering — **48 % of multi-exercise strength workouts** put isolation/carry/core moves in the first half and compound lifts in the second half | **High** | `index.html:3470` (round-robin destroys ordering) |
| 4 | Conditioning lacks pulls in 24 % of workouts; functional lacks pushes in 42 % | **High** | `index.html:3478` (round-robin doesn't enforce minimum coverage) |
| 5 | Cooldown muscle targeting weak — only 25–42 % overlap with main muscles for non-HIIT | **Medium** | `index.html:3201` (scoring uses `Math.random()*0.5` noise that beats real signal when most poses score 0–2) |
| 6 | Difficulty scaling between intermediate and advanced collapses — avg diff 1.42 vs 1.48 (functional), 1.59 vs 1.60 (conditioning), 1.73 vs 1.75 (HIIT) | **Medium** | `index.html:3456` (target diff 1.9 vs 2.7 + Gaussian width 0.5 → almost no separation when only diffs 1/2/3 exist) |
| 7 | Limited profile (untrained + 3 mobility limits + no floor + BMI 32) gets workouts as short as **1 main exercise** with avg 4.0 main moves for 45 min | **Medium** | `js/capability.js:43` (untrained caps `complexity_cap:2`) compounded with no swap-down chain |
| 8 | `Wall Push-Ups`, `Standing Pallof Press`, `Glute Bridge`, `Towel Row`, `Doorframe Row` over-represented (40–106 %); 28 advanced lifts (Zercher, Box Squat, Back Squat, etc.) under 50 reps each across 8 640 workouts | **Medium** | `js/exercises.js` (DB skewed toward gentle bodyweight) + `index.html:3456` (low target diff for beginner) |
| 9 | Cooldown for strength/functional pads to a single mobility-only block; conditioning/HIIT mix cardio + mobility (good); strength loses opportunity for active recovery cardio | **Low** | `index.html:3015` (`COOLDOWN_CATS_BY_TYPE`) |

## Part 3 — Cross-cutting analysis

### Exercise variety

**Conditioning corpus (8 640 workouts, 70 unique exercises in main blocks):** the top 5 cover 60–106 % each. Mean repetition factor (occurrences ÷ workouts) for the top 10 is **0.5×** — meaning the average user sees the same 10 moves in every other workout. The bottom 10 are seen <2 % of the time.

**HIIT corpus (2 880 workouts, 31 unique):** top 11 exercises appear in 100 %+ of workouts. **Variety is essentially zero** — every HIIT workout is some permutation of the same 11 cardio-plyo moves.

**Strength corpus (8 640 workouts, 111 unique):** healthier — top 5 in 36–53 % per-workout. Worst single offender is `Wall Push-Ups`: 47.9 % of workouts contain it (5 868 raw appearances incl. multi-set duplicates), driven by the diff-weighting + compound-priority interaction over-promoting safe bodyweight pushes for any sub-advanced profile.

**Functional corpus (8 640, 71 unique):** top 5 in 53–106 %. `Single-Leg Balance` is the chief offender (it's diff 1 + bodyweight + functional + core — passes every filter).

### Duration accuracy

| Type | Target | Mean | p5 | p50 | p95 | % > 10 % off | % > 20 % off |
|---|---:|---:|---:|---:|---:|---:|---:|
| HIIT | 20 / 30 / 45 min | hits target almost exactly | — | — | — | 0 % | 0 % |
| Yoga | same | hits target ±25 s | — | — | — | 0 % | 0 % |
| Conditioning | 45 min | 2 313 s (38.5 min) | 1 115 s (18.6 min) | 2 700 s | 2 790 s | 12.4 % | 9.9 % |
| Functional | 45 min | 2 491 s (41.5 min) | 1 460 s (24.3 min) | 2 700 s | 2 780 s | 7.3 % | 5.9 % |
| Strength | 20 / 30 / 45 min | always **25–56 % under** | — | — | — | 100 % | 98 % |

The strength row is the [HARNESS-DRIFT] — production should land much closer once the harness is fixed and re-run. The conditioning/functional 45-min p5 of 18–24 min is a real concern: when the exercise pool is small (limited / pregnant / elderly), `mainCount` collapses and `reconcileTotalTime` runs out of cooldown headroom (cap = 30 % of session). The reconcile then silently quits, leaving a 20-minute "45 min" workout.

### Strength sequencing

Of strength workouts with ≥4 main exercises: **2 398 of 5 000 sampled (47.96 %)** put isolation/carry/core moves in the first half AND ≥2 compound lifts in the second half. The round-robin shuffles cats randomly — a Back Squat scheduled after Front Plank is not just suboptimal, it's bad coaching. Sequencing should be deterministic for strength: compounds first.

### ISSUE #1 — Yoga skips capability filter (CRITICAL safety)

**SEVERITY:** critical
**AFFECTED:** all yoga workouts for pregnant / elderly / limited / floor-restricted profiles
**ROOT CAUSE:** `js/yoga.js:381` (`generateYogaWorkout`) builds its pose pool from `posePassesExperience` and `posePassesEquipment` only — it never calls `capability.isAllowed`. Yoga DB poses also lack `pregnancy_safe`, `requires_floor`, and `contraindicated_for` metadata.

**FIX:**

```
FILE:     js/yoga.js
LOCATION: const YOGA_DB = [ ... ]   (lines ~82–290)
BEFORE:   each pose is {name, image, sanskrit, cat, muscles, diff, styles, single_sided, narration, transition_in}
AFTER:    add per-pose safety metadata:
            requires_floor:   true   // for Child's Pose, Cat-Cow, all yoga-floor, Chaturanga, Up-Dog, Down-Dog, Pigeon, etc.
            pregnancy_safe:   'no'   // for Chaturanga, Up-Dog, Cobra, Locust, Bow, Camel, Wheel, Boat, Crow, Headstand, Shoulder Stand, Plow, Revolved Triangle, Revolved Side Angle, Belly-Down Twists
                              'early_only' // for Bridge Pose, Plank, Side Plank, Down-Dog (T2+ ok if knee-friendly), all standing balance poses with deep forward fold
                              'yes'   // for Mountain Pose, Cat-Cow on hands+knees, Easy Seat, Wide-Legged Forward Fold (mild), Tree (modified), Centering, Savasana on side
            contraindicated_for: ['knees']  // for any deep lunge, hero pose
                                 ['lower_back'] // for Cobra, Up-Dog, Wheel, Camel, deep forward folds without knee bend
                                 ['shoulders'] // for Down-Dog, Chaturanga, inversions
                                 ['wrists'] // for Plank, Down-Dog, Crow, all hand-balances

            cats.includes(p.cat) &&
```

**SEVERITY:** medium
**AFFECTED:** all types except yoga

## Part 6 — Timing & rest tuning

Current `js/builder.js` tables and the implied behaviour:

```
BASE['lower-squat'] = {work:40, rest:20}
TYPE_MOD.strength    = {work:1.2, rest:1.4}
DIFF_MOD[2]          = {work:1.0, rest:1.25}
INTENSITY_MOD_BY_TYPE.strength.high = {work:0.85, rest:0.7}
```
For a strength + d2 + high intensity Air Squat:
- work: 40 × 1.2 × 1.0 × 0.85 = 40.8 s → round5 = 40 s
